# wifikit

Аудит Wi-Fi под Linux с GUI: захват рукопожатия/PMKID, оффлайн-брутфорс, злой двойник с порталом-ловушкой.

Только Linux, всерьёз: на macOS родной стек не умеет monitor mode и инъекцию, на Windows режим монитора
требует Npcap и работает через пень-колоду, а AP-режим теряет BSSID. Подробности — `docs/PLATFORMS.md`.

## Что умеет

1. **Скан** каналов с сигналом и разбором RSN IE: WPA2/WPA3, PMF обязательный/разрешённый, подсказка «чем брать».
2. **Захват**: 4-way handshake (с деаутом по кнопке) и PMKID без клиента. Авто-стоп по первому EAPOL, отсев пар по MAC точки, оценка качества (authorized/replaycount).
3. **Крошилка** на hashcat -m 22000: словарь, правила (best64/dive/rockyou-30000), маска, гибрид, очередь, живой прогресс, потифайл проекта. Авто-генерация вендорских кандидатов из SSID/BSSID.
   Отдельно — **перебор по позициям** без словаря: для каждой позиции тип символов (цифры/строчные/ПРОПИСНЫЕ/hex/знаки/любой/свой набор) или фиксированный символ, плюс длина или диапазон длин. Под таблицей сразу видно маску и размер перебора.
4. **Злой двойник**: клон SSID и BSSID, hostapd + dnsmasq + перехват DNS/HTTP через nftables, портал с шаблонами, загрузка своих HTML/ZIP, сбор всех полей формы, «неверный пароль» только после реальной проверки по захваченному хэшу.
5. **Проекты**: папка с дампами, хэшами, логом, результатами. Экспорт отчёта в Markdown/HTML.
6. **Диагностика**: версии, чипы, драйверы, конфликты NetworkManager, тест инъекции, снятие rfkill.

## Железо

Нужны **два** USB-адаптера: один в monitor+инъекцию, второй в AP-режим. Один и тот же интерфейс не годится.

Работают: MediaTek MT7921AU (ALFA AWUS036AXML), RTL8812AU (AWUS036ACH), MT7612U, AR9271 (2.4 ГГц, лучший AP-адаптер).
Не годятся: почти все встроенные карты ноутбуков (Intel/Broadcom), Realtek RTL8811AU/8821CU.

Питание: два мощных адаптера через дешёвый хаб просаживают порт — берите хаб с внешним питанием.

## Установка

Ubuntu 24.04 и новее, Debian 12/13:

```bash
sudo packaging/install.sh
```

Deb-пакет:

```bash
packaging/deb/build.sh 0.1.0 && sudo apt install ./dist/wifikit_0.1.0_all.deb
```

**hcxdumptool 7.x обязателен** (в 6.x другой CLI). Ubuntu 24.04 везёт 6.3 — install.sh соберёт 7.x из исходников
сам; для deb-пакета версию придётся обновить вручную, приложение скажет об этом прямым текстом.

**Ubuntu 22.04 (jammy) тоже работает**: hcxdumptool 7 собирается из исходников (в репозитории 6.2.5), hashcat 6.2.5
не умеет `--status-json` — прогресс и скорость парсятся из обычного `--status`. Проверка пароля требует hcxpmktool;
если его нет, портал честно показывает «проверяем…» и не объявляет пароль неверным.

**PySide6 и Qt-библиотеки**: в Ubuntu 24.04 пакета `python3-pyside6` нет вообще, поэтому install.sh кладёт PySide6
в отдельное окружение `/usr/lib/wifikit/venv` и прописывает этот интерпретатор в лаунчер. Заодно ставятся
`libxcb-cursor0`, `libxcb-icccm4`, `libxkbcommon-x11-0` и прочие xcb-библиотеки — без них Qt пишет
`could not load the Qt platform plugin "xcb"` и окно не открывается.

Из исходников:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python app/main.py
```

## Запуск

`wifikit` из меню или из консоли. GUI работает без root, привилегированный демон поднимается через
pkexec (polkit спросит пароль один раз за сессию).

Порядок работы: назначить адаптеры в шапке → «Точки» → выбрать цель → «Захват» → «Крошилка» → «Злой двойник».

## Ограничения, о которых надо знать заранее

- **WPA3-only** не крошится: в hashcat до сих пор нет SAE. Работает только переходный режим WPA2/WPA3.
- **PMF обязательный** (`ieee80211w=2`) отбивает деаут — интерфейс это показывает и предлагает PMKID.
- Крошилка упирается в GPU. В виртуалке GPU нет: останется CPU и единицы-десятки тысяч H/s.
- DFS-каналы на MT7921/RTL8812 нестабильны, в UI они помечены.

## Структура

```
app/      GUI (PySide6), тема, i18n
daemon/   привилегированное ядро, JSON-RPC по unix-сокету
core/     scan, capture, pmkid, deauth, ap, portal, crack, verify, report
portals/  шаблоны порталов
```

Архитектура и обоснования: `docs/ARCHITECTURE.md`.

## Правовое

Только для сетей, которые вам разрешено тестировать. Активный деаут рвёт соединения соседям.
